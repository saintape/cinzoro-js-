# Cinzoro website

A single-page, dependency-free website for Cinzoro.

## Files
- `index.html` — page structure/copy
- `styles.css` — design + responsive layout
- `script.js` — small reveal/animation behavior
- `favicon.svg` — browser icon

## Before going live
1. Replace `hello@cinzoro.com` in `index.html` with your real contact email if different.
2. Review the ICP wording while you're testing SaaS / consultants / agencies.
3. Deploy the folder as a static site.

## Free deployment path
Use Cloudflare Pages with the GitHub repository containing these files.
